# گزارش مرور تمرین CA3\n\nاین مخزن یک fork شخصی از مخزن رسمی تمرین UT-SWT/F05-CA3 است. هدف تمرین، مرور کد شبیه‌ساز آسانسور و شناسایی Code Smellها و Test Design Patternهای موجود در کد است. طبق صورت‌پروژه، کد اصلی و تست‌های آماده نباید برای رفع smellها اصلاح شوند. خروجی نهایی باید به‌صورت گزارش PDF ارائه شود.\n\n## اجرای پروژه\n\nپیش‌نیازها\n\n- Java 17\n- Maven 3.9 یا بالاتر\n\nاجرای تست‌ها\n\n~~~bash\nmvn test\n~~~\n\n## ساختار گزارش\n\nگزارش نهایی را می‌توان با این بخش‌ها تکمیل کرد\n\n1. مشخصات اعضای گروه\n2. روش بررسی و محدوده کد\n3. Code Smellهای مشاهده‌شده در تست‌ها\n4. Code Smellهای مشاهده‌شده در کد تولیدی\n5. Test Design Patternها و Design Patternهای شناسایی‌شده\n6. اثر هر مورد بر خوانایی، نگهداری یا قابلیت اعتماد تست\n7. پیشنهاد اصلاحی کوتاه\n8. جمع‌بندی\n\nنام فایل تحویلی باید مطابق صورت‌پروژه و با قالب زیر باشد\n\nCA3_Sid1_Sid2.pdf\n\nشناسه اعضای گروه را پیش از تبدیل گزارش به PDF جایگزین کنید.
